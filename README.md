# LCW Pisos — projeto completo atualizado

Esta é a pasta completa para o VS Code, com apenas um arquivo de entrada: index.html.
O visual original, as imagens menores, as dicas e a experiência de instalação e polimento por rolagem já estão integrados.

## Instalar na pasta que você já usa

1. Extraia TODO este ZIP em uma pasta temporária.
2. Na pasta antiga do projeto, preserve a pasta .git, que mantém o histórico e a ligação com o GitHub. Você pode remover os outros arquivos e pastas após guardar uma cópia de segurança.
3. Copie TODO o conteúdo extraído diretamente para a pasta do projeto. index.html e assets devem ficar lado a lado na raiz.
4. No VS Code, abra essa pasta. Clique com o botão direito em index.html e escolha Open with Live Server.
5. No navegador, pressione Ctrl + F5 e role até “Veja a madeira ganhar vida”.

O ZIP não contém uma pasta lcw-pisos envolvendo os arquivos: seu conteúdo já é a raiz do projeto.
Não adicione um arquivo LCW_Pisos_3D_POC.html. Esta entrega já inclui a versão nova no index.html.

Também é possível abrir index.html diretamente no navegador. Não precisa de npm, build ou instalação de pacotes.

## Arquivos

- index.html: página e textos.
- assets/css/styles.css: aparência e responsividade.
- assets/js/main.js: menu, serviços, galeria, dicas, comparador e orçamento.
- assets/js/floor-renderer.js: maquete em perspectiva e polimento.
- assets/js/floor-experience.js: rolagem e controles da maquete.
- assets/images: imagens ilustrativas originais.
- assets/fonts e assets/icons: fontes e ícones locais.
- docs: origem das imagens, licenças e validação da versão atual.
